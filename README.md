## 👨‍💻 About Me

<img align="right" width="340" src="https://raw.githubusercontent.com/abhisheknaiidu/abhisheknaiidu/master/code.gif" alt="Coding animation"/>

I'm **Muhammad Naqsh**, a full-stack developer focused on building web and cross-platform mobile applications.

- 🔧 I build **full-stack web apps** with the **MERN stack** — React on the front, Node.js + Express + MongoDB on the back.
- 📱 I develop **cross-platform mobile apps** with **Flutter & Dart**.
- 🎨 I care about modern UI — Tailwind CSS, smooth animations, and interactive experiences with **Three.js & GSAP**.
- 🌐 Comfortable with **REST APIs** and **Firebase** for real-time, backend-as-a-service workflows.
- 🚀 Always shipping side projects — check my **[portfolio](https://naqsh-portfolio.vercel.app/)**.
